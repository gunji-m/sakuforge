# 入力を信用しない原則

この文書は、sakuforge が受け取る入力と、出力・記録の扱いの原則の正本です。出自は tfdata-api の
`docs/security.md`（main `4a25bc93e8dba5b8bce866d6707bce6415ec61da`）で、サーバー固有の節（認証、
reverse proxy、ホスト、接続経路、秘密情報の注入、DB）を除いた原則だけを引き継いでいます。

## 1. 何も信用しない

次の入力は、すべて信用しません。

- ファイル名、拡張子、MIME タイプ、申告されたサイズ
- 文字コード、行数、列数、ヘッダー、セル値、CSV の構造
- 外部データ（東証の銘柄一覧など）から得た値と、その形式
- 利用者が送る識別子

拡張子や MIME タイプを内容の判定根拠にしません。前段で検証済みであることを理由に、後段の検証を省きません。

## 2. 上限を先に決め、fail closed にする

- サイズ、行数、列数、処理時間、返却件数の上限を、処理を書く前に決める（値は[ドメイン規則](domain-rules.md#1-入力の上限)）
- サイズは上限+1 byte までしか読まずに判定する
- 上限を超えた、または判定できないときは、受け付けずに止める。部分的な結果を完全な結果として返さない
- 推測で補正しない。[ドメイン規則](domain-rules.md)で明示的に許した正規化（見出しと数値セルの外周の ASCII 空白の除去）
  だけを行い、それ以外の空白除去、大文字化、全角変換、切り詰め、profile の推測をしない
- 圧縮ファイル、複数ファイル、リモート URL は、専用の上限と検証を設計するまで受け付けない
- 上限を広げるときは、メモリと処理時間を見積もり直す

## 3. 出さない

出してよい範囲を、正常応答とそれ以外で分けます。

**正常応答**: 招待確認を通った当該リクエストへの正常応答には、[ドメイン規則](domain-rules.md)で定義した
集計値（総資産額、年間配当見込み、業種構成比）と、所見・件数・照合結果だけを返してよい。CSV 原文、保有明細
（行ごとの株数・価格）、ファイル名、例外文は返さない。

**それ以外**: ログ、エラー応答、監視、テストの失敗メッセージ、スクリーンショット、作業報告、公開資料には、
次を出しません。

- 資産値（株数、価格、評価額、集計値）と CSV の内容（元のヘッダー、セル値）
- ファイル名、メールアドレス
- 内部 path、スタックトレース、依存ライブラリの例外文、生の例外の文字列
- 秘密情報

利用者へ返す文言は固定の文言にし、例外の文字列を埋め込みません。記録が必要なら、成否、件数、処理時間、
固定 code などの安全な項目だけを構造化して残します。

## 4. 実データを置かない

実データ（実際の保有 CSV、実際の銘柄一覧、実在の資産値）を、リポジトリ、CI、テスト、fixture、Issue、PR、
共有資料に置きません。テストと例は合成データだけを使います。境界のデータはテストの中で生成し、
巨大な固定 fixture を足しません。

## 5. CSV Formula Injection

`=`、`+`、`-`、`@` などで始まるセルは、表計算ソフトで式として実行され得ます。

- 元のセル値を出力しない間は、escape 処理をしない
- CSV や元の値を出力する機能を足すときは、その出力境界の対策を先に設計する

## 6. 依存の採用基準

新しい依存を足す前に、Issue か PR に次を記録します。

1. 解決する要件と、標準ライブラリ・既存の依存・機能を削ることでは満たせない理由
2. どこで使い、侵害されたときに何へ影響するか
3. 公式の配布元、license、security の連絡先、保守者と保守の実績
4. 既知の脆弱性、install 時の script や通信の有無
5. version と hash の固定方法
6. 代替の候補と、自作した場合の保守の負担
7. 要らなくなったときの外し方

知名度や star 数だけで採否を決めません。認証、暗号、標準仕様の parser は自作しません。

例外として、保有 CSV の構文解析（カンマ区切り、`"` の引用と `""` のエスケープ、改行）は `packages/core` に
自作します（2026-11-03 本人判断、#25）。扱う構文がこの範囲だけと狭いこと、所見に物理行番号を付け、上限を
走査中に判定し、不正な構文を補正せずに拒否する（fail closed）必要があることが理由です。入力の大きさに対して
時間とメモリが線形になるように書き、規則ごとのテストと、上限の大きさの入力のテストで確かめます。
