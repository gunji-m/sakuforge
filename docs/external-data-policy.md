# 外部データとの約束

この文書は、sakuforge が使う外部データ（銘柄マスター）の扱いの原則です。出自は gunji-m/tfdata-api の
`docs/jpx-master-data-policy.md` と ADR 0005（main `4a25bc93e8dba5b8bce866d6707bce6415ec61da`）で、
原則だけを引き継いでいます。この文書はプロジェクトの保守的な利用判断であり、法的助言ではありません。

東証からの個別回答の原文は本人が private に保持します。

## 1. 取得元

- 銘柄マスターの取得元は、株式会社東京証券取引所の月次「東証上場銘柄一覧」Excel とする
- 公式の配布形式は Excel。CSV と誤記しない
- J-Quants は使わない
- 他の取得元を使う場合は、取得元ごとに利用条件を確認し、新しい ADR で決める

## 2. 加工と表示の範囲

- 月1回、手元で Excel を取得・検証し、必要な列だけを抽出して銘柄マスター JSON を生成する
- 用途は、保有 CSV の証券コードの照合と、[ドメイン規則](domain-rules.md)の構成計算と表示に必要な項目だけ
- 元の Excel ファイルは利用者に配らない
- Excel を信用しない。形式、sheet、ヘッダー、列、型、文字数、件数、基準日を上限付きで検証し、失敗したら
  部分的な銘柄マスターを作らない（[入力を信用しない原則](input-trust-principles.md)）
- 少数招待での利用範囲と、銘柄マスター JSON をどこまで配ってよいかは #3 で確認する

## 3. 出典表示と基準日

銘柄マスター由来の情報を利用者へ表示するときは、可能な限り次を表示します。

`出典：株式会社東京証券取引所「東証上場銘柄一覧」（YYYY年MM月末時点）`

- 基準日を表示できない場所では括弧内を省略できる
- 基準日と取得日時を分けて持つ。月末時点の一覧を、現在の最新データのように表現しない

## 4. リポジトリに置かないもの

このリポジトリは Public です（[ADR 0002](decisions/0002-public-repository.md)）。

- 銘柄マスター JSON と元の Excel を置かない。置き場は `.gitignore` の `data/stock-master/` に予約している
- 実在の銘柄コード一覧、会社名を、fixture、CI の出力、Issue、PR、共有資料に置かない。テストは合成データだけ
- 東証からの個別回答の内容、日付、担当、やり取りを書かない

## 5. 条件が変わったとき

- 東証が月次 Excel の公開や利用条件を変えたら、新しい取得と生成を止めて、利用範囲を確認し直す
- 利用者の範囲、提供の形（JSON をブラウザへ配る等）、商用性が変わる場合は、変える前に利用範囲を確認する
- 誤って配布したときは、配布を止め、対象を削除し、影響範囲を確認する
