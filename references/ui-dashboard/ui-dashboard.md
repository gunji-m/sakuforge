# ダッシュボード画面の参考例

> この文書とモック・画像は、画面のデザインの参考例で、仕様の正本ではない。数値は架空。結果 JSON の形は `docs/design.md` 8 節、規則は `docs/domain-rules.md` と `docs/input-trust-principles.md` に従い、食い違うところは正本を優先する。

> 段階 2 の画面の範囲は `docs/design.md` 6 節で決めた（#67、2026-11-11）。この参考例にある部品のうち、ファイル名、「該当行を見る」、利回り、推移グラフと期間タブ（期間の増減、最高値、取り込み回数を含む）、「結果 JSON を保存」は、段階 2 の画面に入れない。書体は Noto Sans JP を同梱する。モックと画像は直していない。

対象：CSV 取り込み後に表示する結果画面。モックは `mock/dashboard-17.html`（17 業種）と `mock/dashboard-33.html`（33 業種）。1440×900 を基準に、縦スクロールを出さない。

## 方針

- 画面に置くのは集計結果の数字と図だけ。集計から文章を生成して添えない（「○○に集中」のような解釈文は置かない）。
- 通知はエラー・注意のときだけ出す。問題がなければ通知の帯は存在しない。
- 1 画面で完結する。入らないものは切替（トグル）か別画面に逃がす。
- 色・書体・余白は「俺好みデザインシステム」に従う（白地、Noto Sans JP、青 `#2a5db0` を主役に）。

## 部品と入力データ

| 部品 | 表示 | 入力（結果 JSON から） | 備考 |
| --- | --- | --- | --- |
| ヘッダー情報 | ファイル名、銘柄数、検査日時、マスター基準月、「結果はブラウザにだけ保存」 | `source.fileName`, `summary.count`, `checkedAt`, `master.asOf` | 文言は固定。 |
| 通知の帯 | 件数、理由、該当行番号、「該当行を見る」、閉じる | 所見 code が `UNMATCHED_CODE` 等の件数と行 | 件数 0 なら描画しない。文言は code ごとの固定 message。 |
| ドーナツ | 上位 7 業種＋その他、中央に保有業種数／総業種数と上位 3 合計 | 業種別構成比（評価額ベース） | 色は `chart-1`〜`chart-8`（下記）。8 区分固定。 |
| 業種別の横棒 | 全業種を構成比の大きい順、未保有は 0 で点線 | 業種別構成比、業種区分（17 / 33） | 17：1 列、行 16px、文字 12px。33：2 列、行 13px、文字 11px。 |
| 17 / 33 切替 | ピル型トグル | — | 既定は 17。選択は端末に記憶してよい。 |
| 評価額パネル（左） | 現在値、選択期間の増減額と率、年間配当見込み（税引前）と利回り、最高値、取り込み回数 | 今回と過去の結果 JSON | 配当見込みは入力データが要る（未決、下記）。 |
| 推移グラフ（右） | 取り込み日ごとの点を直線でつなぐ。薄い面。ホバーで縦の点線と「日付 取り込み／金額／前回比」 | 過去の結果 JSON の `summary.totalValue` と `checkedAt` | 日次補間はしない。点＝取り込み。 |
| 期間タブ | 直近 3 回／6M／1Y／全期間 | — | 既定は 1Y。 |
| 評価額／配当見込み切替 | ピル型トグル | — | 切替でグラフの系列が変わる。 |

## 色・書体

- 主役 `#2a5db0`、薄い面 `#e6eef9`、注意 `#b8541f`

- 書体：Noto Sans JP。見出し 700、本文 400
- 角丸：カード 16px、ボタン・トグルは pill（999px）

## 状態

- 通知なし（照合 0 件）：帯が消え、上段がその分広がる
- 通知あり：帯 1 行。複数種の所見があるときは件数の多い順に 1 行ずつ、最大 2 行
- 17 ↔ 33：横棒パネルだけ再描画。他は不変
- 取り込みが 1 回だけ：推移グラフは点 1 つと「比較するには 2 回以上の取り込みが必要」の固定文。期間タブは無効
- 初回（履歴なし）：この画面ではなく CSV 選択画面（別途）

## design.md との差分・未決

決まったことは `docs/design.md` 6 節にある（#67、2026-11-11）。

1. **推移グラフ**：段階 2 には入れない。結果は `localStorage` に保存しておき、推移は段階 3（#4）で足す。
2. **照合エラーの詳細画面**：「該当行を見る」は入れない。未知の証券コードは一覧だけを出す。
3. **未保有の業種の点線**：出す。応答の `sectors` に、保有の無い業種が構成比 0.00・`held` が false で入る（`docs/design.md` 8.2、#81）。
4. **33 業種の文字 11px**（未決）：デザインシステムの下限（14px、注釈 12px）を割る。例外として認めるか、業種名を省略形にして 12px に上げるかは、画面の実装の中で決める。
